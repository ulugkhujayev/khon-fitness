READ. Reviewed frozen head `5d3b553049284dc7f2e1897eb45162f4dfa2d82e`, the phase 2 contract, and the phase 1 rules it uses. The source is the pre-build baseline. The cases below are design predictions. No app tests ran. [Phase 2 contract][p2] · [Common design][common]

| D27 | Stale band record | The provider changes the bounds or modality of an original member of an open draft while keeping its ID, or removes that member. | D29 | Stale pending count | Today still shows one import while the timer ends a covering run in the background. An earlier count read may still be in flight. | Refresh the visible count on changes that affect eligibility, including a committed run range. Discard a count based on the older eligibility state. The list and count agree once both read the current state. |
| D30 | Swim merge | A records a 25 m pool and has no lap count. B records 20 laps in a 50 m pool without a distance field. The owner confirms the pair. | Treat lap count and pool length as a pair when filling missing values. Block this merge and preserve both inputs. A compatible lap count can still fill a missing count. |
