# Research brief: is there an existing app that matches Khon Fitness?

Owner: one person, Galaxy S8 on Android 9 today, may move to a newer Android or iOS later.
Wearables: Mi Band 9 (Mi Fitness app) and Galaxy Watch 8/9 (Samsung Health). Both feed Health Connect.
Data must stay on the phone or be exportable as plain JSON/CSV. No account lock-in.

## What the owner has today (built as a private Android app)
1. Gym logging: many named programs, one active; blocks with optional supersets (A1/B1 pairing); weight + reps per set prefilled from the last session; one-tap "set done"; swap an exercise for this session only or for the program; muscle tags per exercise; volume, best sets, Epley e1RM chart; sets per muscle per week.
2. Cardio: exercises like "Zone 2 run", "Zone 2 swim", "Norwegian 4x4 bike", "Tabata bike". Steady sessions log time, distance, pace, laps for swim, avg HR, avg watts. Interval sessions run a full-screen timer (warm-up, work, rest, rounds) with voice cues, beeps, lock-screen countdown; per-round HR and watts.
3. Week plan: a template (Mon swim, Tue gym, Wed run, Thu 4x4, Fri swim, Sat gym, Sun rest) plus per-date overrides; move a workout to another day in a calendar.
4. Bodyweight quick entry and chart.
5. Import of finished sessions with HR/distance from Health Connect (Mi Fitness + Samsung Health), merging overlapping band + watch records.
6. Dark, dense UI: no cards with per-row buttons, no captions, no pills, no horizontal scroll rows. Home-screen widget with today's item and a Start button.
7. Offline. JSON export/import. Free. Self-updating from GitHub releases.

## What the owner wants next
8. Stretching / mobility tracking: routines with per-stretch timers, animations or video showing how to do each stretch, history.
9. Meal intake window (time-restricted eating): the app icon itself changes to show whether the eating window is open or closed; window start/end, reminders, history.

## Question
Which existing apps (free, paid, open source; Android and/or iOS) cover this? Score each against items 1-9. Be exact about gaps.
