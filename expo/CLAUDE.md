## What this project is

A cross-platform React Native (Expo) rewrite of **Khon Fitness**, a
one-person gym, cardio and stretching log that exists today as a native
Android app: https://github.com/ulugkhujayev/khon-fitness (Kotlin, Jetpack
Compose, Room; owner Mirzohid). That repo is the source of truth for
behavior. Never push to it.

To read the original while porting:

```sh
git clone --depth 1 https://github.com/ulugkhujayev/khon-fitness.git ../khon-fitness
# screens:  android/app/src/main/java/dev/mirzohidkhon/khonfitness/ui/screens/
# widgets:  .../ui/components/   theme: .../ui/theme/Theme.kt   nav: .../ui/KhonNav.kt
# data:     .../data/ (Entities.kt, Repository.kt, Dao.kt, Stretching.kt, StretchDemo.kt)
# timer:    .../timer/ (TimerService.kt, TimerState.kt, CueGate.kt)
# tests:    android/app/src/test/java/...  mockup: mockup/   QA notes: docs/
```

## Decisions (settled with the user)

- Own private repo `MametovUral/khon-fitness-expo`, app at the repo root.
- Android and iOS are equal targets. No web target.
- UI language English only, as in the original (`docs/SPEC.md`).
- **Bun only**: `bun install`, `bun run …`, `bunx …`. Never npm/npx/yarn.
- Package and bundle id `dev.mirzohidkhon.khonfitness.expo`, so it installs
  next to the Kotlin app.
- `android/` and `ios/` are generated by `bunx expo prebuild` **and
  committed** (user's request). Change native config in `app.json` / config
  plugins, then `bunx expo prebuild --clean`; never hand-edit them.
  `pod install` runs on the Mac.
- `docs/SPEC.md` and `docs/DESIGN.md` (copied from the original) bind every
  screen: HIG dark palette, Inter, grouped inset lists, one primary button
  per screen, no captions or pill badges, number widget with − / + .

## Stack

Expo SDK 57, React Native 0.86, TypeScript strict, Expo Router (routes in
`src/app/`), expo-sqlite, expo-file-system (new `File`/`Paths` API),
expo-sharing, expo-document-picker, expo-crypto, expo-symbols,
expo-system-ui. Check the SDK 57 docs before using any Expo API
(see AGENTS.md); do not code Expo APIs from memory.

## Code map and conventions

- `src/theme/index.ts`: `K` colors, `Type` text styles, `Space`; same names
  and values as `Theme.kt`. Fonts load in `src/app/_layout.tsx`.
- `src/components/`: `ui.tsx` (ScreenTitle, SectionTitle, TextButton,
  PlusButton, PrimaryButton, GroupedList, ListRow with dot/dotFilled/color,
  Empty, `fmt`), `NavBar.tsx` (56 pt bar, round back button), `Screen.tsx`
  (`TabScreen`, clears the floating tab bar), `TabBar.tsx` (floating capsule).
- `src/domain/`: pure TypeScript, **no Expo or React imports**, so `bun test`
  runs it. `types.ts` (entities with Kotlin field names, `Defaults` = Kotlin
  constructor defaults), `dates.ts` (local `yyyy-MM-dd`, ISO weekday 1..7;
  never use UTC/`toISOString` for dates), `plan.ts` (`itemFor`, `PlanRules`),
  `session.ts` (`buildSetLogs`, `previousByKey`, `epley`), `window.ts`
  (`EatingWindowRules`), `format.ts` (`dur`, `preview`), `backup.ts`
  (`parseBackup`, `describeBackup`), `seed.ts`.
- `src/db/`: `schema.ts` (Room v4 DDL verbatim, 17 tables, `COLUMNS`,
  `BOOL_COLUMNS`), `rows.ts` (bool 0/1 conversion, upsert SQL),
  `database.ts` (`getDb` with `PRAGMA user_version` migrations, `all`/`first`/
  `count`, `write(tx => …)` = serialized transaction queue that notifies
  table listeners), `useLive.ts` (hook that re-runs a query when its tables
  change; the Room `Flow` equivalent), `repository.ts` (port of
  `KhonRepository`), `backupFile.ts` (share sheet export, picker import),
  `DataProvider.tsx` (opens + seeds before screens render; hides splash).
- All writes go through `write()`; screens read with `useLive(query, tables)`.
- Ids: `newId()` in `src/db/id.ts`, 8 hex chars like Kotlin.
- Backup JSON keys match the Kotlin `Backup` class, both directions.
  Missing keys take Kotlin defaults on import (kotlinx omits defaults).
- New logic goes in `src/domain` with a `bun test` case in `tests/`. Port the
  matching Kotlin unit test when one exists.

## Stages

0. **Done.** Expo base: tabs, theme, shared components.
1. **Done.** Data layer: schema, repository, seed, backup import/export,
   Settings screen (export, import with merge/replace, reset). Today shows the
   resolved item for today; Programs lists programs and the library rows.
   Native projects prebuilt and committed.
2. **Next: Gym.** Port from `TodayScreen.kt`, `SessionScreen.kt`,
   `ProgramsScreen.kt`, `Editors.kt`, `Common.kt`, `components/Components.kt`:
   - Today: week strip (Mon..Sun, dots per DESIGN.md "Today"), tap a day to
     see or change its item (override, swap via `PlanRules.canSwap`), Start,
     resume an unfinished session, bodyweight sparkline + add field.
   - Number widget (− value unit +, no native spinner) as a shared component.
   - Live session (`session/[id]`): blocks with set rows per DESIGN.md "Set
     row", one tap logs a set, focus moves to the next kg field, green delta
     vs last time, swap exercise (session only or also the program), Finish.
   - Program editor, block editor, exercise library + editor (archive,
     merge into, delete only when unused via `exerciseUsage`), modalities,
     week plan (`saveWeekPlan` freezes past days).
3. History: month calendar with session dots, session detail, bodyweight
   chart, per-exercise e1RM chart (Epley), top set, recent sessions table.
4. Cardio: cardio session screen, interval timer with cues that keeps running
   in the background (Kotlin uses a foreground service), manual entry.
5. Stretching (routine player, 3D demo figures from `StretchDemo.kt` /
   `tools/stretch-demo`) and the eating window (sheet, reminders).
6. Platform: Health Connect (Android) and HealthKit (iOS) import, home-screen
   widgets, EAS Update instead of the APK self-updater.
7. EAS Build and signing for both stores.
